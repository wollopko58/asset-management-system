# Services Layer

หน้าที่:
- จัดการ Business Logic ของระบบ
- รวมขั้นตอนการทำงานที่ซับซ้อน
- ประสานงานระหว่าง Controller และ Repository

หลักการ:
- ไม่ควรเขียน SQL โดยตรง
- ไม่ควรจัดการ Request / Response
- รับข้อมูลจาก Controller แล้วส่งผลลัพธ์กลับ

ตัวอย่าง:
- ตรวจสอบเงื่อนไขการจองห้องพัก
- คำนวณราคา
- ตรวจสอบสิทธิ์การใช้งาน
